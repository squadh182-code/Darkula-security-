# 🛡️ Discord Security Bot

A Discord security bot with protection and moderation features.

## Features

- Anti-Nuke
- Anti-Raid
- Anti-Spam
- Invite & Link Protection
- Bot Protection
- Channel Protection
- Role Protection
- User Whitelist
- Role Whitelist
- Channel Whitelist
- Voice Channel `/join`
- Voice Channel `/leave`

## Requirements

- Node.js
- Discord Bot
- Railway or another Node.js hosting service
